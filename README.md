# 🚀 Bootstrap Admin Dashboard & Order Management System

A responsive, feature-rich admin dashboard built with **HTML5**, **Bootstrap 5**, **jQuery**, and **Chart.js**. It features full Order Management (CRUD capabilities), real-time CSV Data Export, Theme Switching (Dark/Light mode), and LocalStorage persistence.

---

## ✨ Features

- **📊 Interactive Analytics Dashboard**: Sales and traffic visualization using Chart.js.
- **📦 Order Management System**: View, add, delete, and filter orders in real time.
- **📥 CSV Data Export**: Instant export of order records to an Excel-compatible `.csv` file.
- **🌗 Dark / Light Mode**: Seamless theme switching with persistent settings.
- **👤 Profile & Preferences Update**: In-place profile/settings updates with instant toast notifications.
- **📱 Fully Responsive**: Custom layout optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend Framework**: [Bootstrap 5](https://getbootstrap.com/)
- **Scripting & DOM Handling**: [jQuery](https://jquery.com/)
- **Data Visualization**: [Chart.js](https://www.chartjs.org/)
- **Icons**: [FontAwesome](https://fontawesome.com/)
- **Data Storage**: Browser `localStorage`
